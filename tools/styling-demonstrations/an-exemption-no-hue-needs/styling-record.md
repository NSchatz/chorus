# A styling record exempting a role that is already neutral

A copy of the table in `docs/styling-conventions-record.md` with ONE thing
wrong: S10's exemption names `--mark` beside `--focus`, and `--mark` is a near
black in the light theme and a near white in the dark one. It has no second hue
for the exemption to hold up.

An exemption that costs nothing is how the list of them grows: each name added
is harmless on the day it is added, and the rule that cited the clause ends up
measuring whatever is left. So a name here that does not need the exemption is a
refusal, and the row can only ever carry the roles that would go red without it.
