# pinned micromamba (tools/qemu/pins.conf), which refuses a package whose digest
# differs, and verifies an existing environment against it.
# tools/conventions/check-pins.sh holds every line to that form.

# audio clients; a headless run loads the library and uses none of them). Each
# package's licence is in the decision record. None of this is linked into or
# shipped with chorus: the libraries are loaded by the emulator, a tool.
