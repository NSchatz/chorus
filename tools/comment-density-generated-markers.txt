# comment block carries one of these is excluded from the ceiling: a generator's
# prose is the generator's to change, and holding it to a ratio would be a
# demand on whoever writes the generator's template rather than on any author of
# this repository.
#
# Blank lines and lines starting with # are ignored. An empty list is a
# legitimate state. Matching is a substring test against the comment's text
# with its markers taken off, so the marker is written here as it appears in the
# comment.
#
