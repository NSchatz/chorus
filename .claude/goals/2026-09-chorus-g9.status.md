## Decisions taken

- 2026-09-30: the interactive shell's `grep` function fails here, as §0.11 predicts; the goal uses
  `command grep` and `rg`.

- 2026-09-30: flash guard (PR #62): `check-flash-guard.sh` is a per-language whitelist, every read tied to a comparison against 1; refusal messages say "the owner-at-bench variable" rather than spelling the name (a spelled name would be an occurrence outside the read forms); the check and the behavioural test are the only unscanned scripts and the fixture test fails if that list grows.

- 2026-09-30: controls (PR #63, ADR 0063): the pairing button is a local event only (adoption is goal 14's); the sub level knob only cuts (-12.0 to 0.0 dB) so no position exceeds a room limit (K81, I10), level and phase stay on the endpoint until goal 12's DSP; the two-way's rear light never follows the visualizer (K68); play/pause/next come back from the server as a transport request for the input path (goals 16, 17). ASSUMED: debounce 20 ms, long press 1 s, volume repeat 600/300 ms, step 5, knob hysteresis 24 codes, visualizer stale 500 ms, beat threshold 128, the LED palette, a linear volume step until goal 11. No GPIO/LEDC/ADC binding: the reference board has no controls; goals 24-26 place the pins (boards Needs item). Red round 1 of #63: `audio-path.conf` lacked the new server file.

- 2026-09-30: amp (PR #64, ADR 0064): the I2C address 0x4C (ADR strap to GND) is ASSUMED: the maker's Apache-2.0 config names no strap and its driver repo is GPL-3.0 (README read only, no source); the boards Needs item or S5 settles it, a wrong address is refused as `amplifier-did-not-answer` with the stage dead. The clock-fault bit is excused only before the clock starts, then the latch is cleared and all three fault registers re-read with nothing excused before Play; WARNING (0x73) not graded. Faults after the clock start unwind PDN low then stop the clock; new status `amplifier-did-not-reach-play`. No DSP coefficients loaded (ROM flow, 0 dB digital volume; goal 12 decides). `endpoint.conf` must stay under the 16 KiB read buffer (15,760 bytes now), so citations are short. BRIEF section 5.5 corrected three times (waits 5 ms; faults 0x70-0x72; 32 or 64 BCLK per frame), dated with K47.
