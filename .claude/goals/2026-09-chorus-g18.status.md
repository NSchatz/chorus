## Decisions taken

- D1 (2026-10-04): the quality-scale tier is Platinum's rule set (all 54 rules of Bronze, Silver,
  Gold and Platinum), self-certified in `quality_scale.yaml`, as the research recommends
  (`research-ha-integration.md` §1.1, R1.1; the verifier confirmed the tier facts). A custom
  integration cannot hold a tier; it aligns with one. Reasoning: the research file and the
  integration's ADR (to be written by B.2).
- D2 (2026-10-04): the harness pin is `pytest-homeassistant-custom-component` 0.13.366 (HA
  2026.9.3, the homelab's pin), on a uv-managed Python 3.14, locked with hashes. The pin moves
  when the homelab's HA pin moves; the file that records it cites the homelab commit.
- D3 (2026-10-04): the catalog has no announce command and no server identity; the integration
  needs both (a config entry needs a stable unique id; line B names announce). This goal adds
  the smallest honest seam in the server (B.1): the clip plays as the target's source through
  a held player and what played before is restored. Goal 20's ducking mixer (K31) replaces the
  interrupt-and-restore, not the command. Reasoning: the server ADR (to be written by B.1).
- D4 (2026-10-04): two build tracks (the server seams; the integration) and one adversarial
  check, not five agents: usage stood at 83 % of the 95 % ceiling at start.
