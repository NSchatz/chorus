## Decisions taken

- D1 (2026-10-04): the quality-scale tier is Platinum's rule set (all 54 rules of Bronze, Silver,
  Gold and Platinum), self-certified in `quality_scale.yaml`, as the research recommends
  (`research-ha-integration.md` §1.1, R1.1; the verifier confirmed the tier facts). A custom
  integration cannot hold a tier; it aligns with one. Reasoning: the research file and the
  integration's ADR (to be written by B.2).
- D2 (2026-10-04): the harness pin is `pytest-homeassistant-custom-component` 0.13.366 (HA
  2026.9.3, the homelab's pin), on a uv-managed Python 3.14, locked with hashes. The pin moves
  when the homelab's HA pin moves; the file that records it cites the homelab commit.
- D3 (2026-10-04): the catalog has no announce command and no server identity; the integration
  needs both (a config entry needs a stable unique id; line B names announce). This goal adds
  the smallest honest seam in the server (B.1): the clip plays as the target's source through
  a held player and what played before is restored. Goal 20's ducking mixer (K31) replaces the
  interrupt-and-restore, not the command. Reasoning: the server ADR (to be written by B.1).
- D4 (2026-10-04): two build tracks (the server seams; the integration) and one adversarial
  check, not five agents: usage stood at 83 % of the 95 % ceiling at start.

- D5 (2026-10-04): track S's own choices, kept: the record is ADR 0136 (the adrs check ties a
  record's number to its PR's); "no players" and "no free player" are refused with field `t`, as
  `no-receivers` is; an alarm ringing in a room that would hear the clip refuses the announce; a
  failed fetch is answered 200 and restores afterwards; a cast or a Spotify receiver does not come
  back after a clip (the group goes to `none`, never to a dead player); no `chorusctl announce`
  (a follow-up). Reasoning: `docs/decisions/0136-a-server-identity-and-an-announce-command.md`.
- D6 (2026-10-04): other work in NSchatz/chorus while this goal runs (§0.13): PR #135 (the owner's
  branch `owner/public-ci`) and PR #137 (the goals program's `goals-archive-g5/pin-citation`).
  Neither is this goal's; none of their branches or files is touched.

- D7 (2026-10-04): track H's own choices, kept: unjoin is `take` on the room (v1 `ungroup`
  dissolves nothing); turn_off is `take` with source `none`; transport is offered only while the
  source is a Spotify receiver; browse is the inputs only; ten rules are exempt (no credentials;
  private and vendored; no action, condition or trigger of its own; nothing polled; no options
  flow; no diagnostic or config entity yet); `brand/` holds a generated icon; uv 0.12.22 is
  pinned in `mise.toml`; the manifest's `codeowners` holds the repository namespace's handle, the
  form hassfest's `integration-owner` rule needs, and the identity scan passes. Reasoning:
  `docs/decisions/0138-the-home-assistant-integration.md`.
- D8 (2026-10-04): PR #138's branch had a commit of its own with a 108-character subject; the
